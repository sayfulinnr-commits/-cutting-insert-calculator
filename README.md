# CutCalc

Веб-приложение для расчёта закупки сменных режущих пластин в серийном производстве.

## Что умеет

- считает расход **режущих кромок**, а не просто количество пластин;
- поддерживает несколько операций и отдельных проходов;
- учитывает количество **активных пластин одновременно**;
- позволяет задавать ресурс как `деталей на одну кромку` или напрямую как `кромок на деталь`;
- объединяет одинаковые закупочные позиции по `артикул + производитель + марка`;
- отдельно учитывает `MOQ` и **упаковочную кратность**;
- добавляет страховой запас и округляет физическую закупку вверх;
- хранит библиотеку инструментов, историю расчётов и карты наладки в браузере;
- создаёт версионируемую карту наладки;
- экспортирует заявку CSV;
- поддерживает резервные копии с проверкой структуры.

## Расчётная модель

Для каждого прохода:

`кромок/деталь = 1 / деталей-на-кромку`

или, если задано напрямую:

`кромок/деталь = введённое значение`

Далее:

`расход кромок = серия × кромок/деталь × активных пластин`

После объединения одинаковых закупочных позиций:

`потребность с запасом = расход кромок × (1 + запас/100)`

`базовые пластины = ceil(расход кромок / кромок на пластину)`

`пластины с запасом = ceil(потребность с запасом / кромок на пластину)`

`минимум к заказу = max(пластины с запасом, MOQ)`

`к закупке = ceil(минимум к заказу / упаковочная кратность) × упаковочная кратность`

### Важное определение

Поле **«Активных пластин одновременно»** означает количество режущих пластин, которые реально одновременно участвуют в обработке детали. Это не складской остаток и не количество пластин, установленных «для удобства».

## Хранение данных

Данные хранятся локально в браузере (`localStorage`) и имеют `schemaVersion`. Старые ключи `cutcalc_v4` / `cutcalc_v3` подхватываются при первом запуске новой версии.

Резервную копию рекомендуется делать перед крупным обновлением библиотеки или переносом на другое устройство.

## Ограничения текущей версии

- ресурс инструмента пока задаётся пользователем; автоматического определения стойкости по материалу и режимам нет;
- расчёт времени резания и ресурса в минутах/кромку — следующий этап;
- CSV является табличным экспортом, это не нативный XLSX;
- библиотека не заменяет официальные каталоги производителей: значения ресурса, числа кромок, MOQ и режимов должны быть проверены технологом/поставщиком.
